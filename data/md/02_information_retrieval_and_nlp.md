# 信息检索与自然语言处理讲义

## 倒排索引与布尔检索模型 (Inverted Index)
倒排索引是现代搜索引擎与文档检索系统的核心基石。它由词典（Vocabulary / Lexicon）和倒排记录表（Posting List）两部分构成：词典存储语料库中所有切分出的独立词项（Term），每个词项指向一条按文档 ID 升序排列的倒排链表，记录该词项出现在哪些文档（DocID）、词频（TF）以及出现位置偏移（Positions）。

在布尔检索与短语查询中，可通过双指针合并算法或跳表（Skip List）快速求取多个倒排链表的交集（AND）、并集（OR）与差集（NOT）。配合中文分词组件（如基于前缀词典与动态规划最大概率路径 + HMM 新词发现的 Jieba 分词），并过滤停用词与标点符号，可构建高效的中文课程知识倒排索引。

## TF-IDF 向量空间模型与余弦相似度
TF-IDF（Term Frequency - Inverse Document Frequency）通过词频（TF）与逆文档频率（IDF）的乘积评估一个词对文档集内某篇文档的重要程度。词频 TF(t, d) 表示词项 t 在文档 d 中出现的频率；逆文档频率 IDF(t) = log((1 + N) / (1 + df(t))) + 1，其中 N 为文档总数，df(t) 为包含词项 t 的文档数。一个词在当前文档出现越多、在其他文档出现越少，其区分度与 TF-IDF 权重越高。

将查询 Query 与每个文档块 Chunk 表示为高维词表空间中的稀疏 TF-IDF 向量后，通过计算余弦相似度 Cosine(q, d) = (q · d) / (||q|| * ||d||) 即可消除向量绝对模长差异，量化查询与知识块的语义相关度。

## BM25 概率检索模型原理与超参数调节
Okapi BM25 是信息检索领域最经典的概率相关性评分算法，在工业界搜索引擎（如 Elasticsearch / Lucene）与 RAG 混合检索中被广泛采用。相比传统 TF-IDF 中得分随词频线性无限增长的缺陷，BM25 引入了两个关键非线性调节机制：

1. 词频饱和度参数 k1（通常取 1.2 ~ 2.0，本系统默认 k1 = 1.5）：控制词频对得分贡献的上限渐近线，防止某个关键词在段落中高频重复导致评分失真。
2. 文档长度归一化参数 b（取值范围 0 ~ 1，本系统默认 b = 0.75）：通过文档长度 dl 与语料平均长度 avgdl 的比值 (1 - b + b * dl / avgdl) 对长文档进行惩罚，消除长文本因包含更多词汇而天然容易命中的偏置问题。

## RRF 倒数排名融合与多引擎混合检索 (Hybrid Search)
单一检索引擎往往存在召回盲区：词级 TF-IDF 擅长精确匹配专业词汇，BM25 擅长长短文本均衡打分，而字符级 N-gram 能够容忍分词边界切碎问题。混合检索（Hybrid Search）通过并行调用多路异构检索引擎，并利用倒数排名融合（Reciprocal Rank Fusion, RRF）算法合并排序结果：

RRF_Score(d) = Σ 1 / (k + rank_i(d))，其中平滑常数 k 通常设为 60，rank_i(d) 为文档 d 在第 i 个引擎中的排名位次。RRF 无需对不同量纲的引擎原始分值做复杂的分布校准，即可稳健提升 Top-1 与 Top-K 综合召回率。

## Markdown 结构化语义分块策略 (Semantic Chunking)
在构建课程问答系统与 RAG（检索增强生成）知识库时，若简单按固定字符窗口硬切分，极易截断完整的公式推导、代码块或逻辑段落，并丢失章节上下文。结构化 Markdown 语义切分器通过识别一级至三级标题（# / ## / ###）维护当前章节路径（Section Hierarchy），在段落空行边界与最小/最大分块阈值处执行自适应切分，并将章节标题注入分块特征向量中，大幅提升问答召回的上下文完整性。

## 信息检索系统评测指标 (Precision@K / MRR / NDCG)
评估问答检索引擎质量的核心离线与在线指标包括：
1. Precision@K（前 K 准确率）：前 K 个返回结果中与问题真正相关的文档比例；Hit@K（命中率）：前 K 个结果中至少包含一个正确答案的查询比例。
2. MRR（Mean Reciprocal Rank，平均倒数排名）：第一个命中相关文档所在排名倒数（1 / rank）的平均值，重点衡量 Top-1 首条结果的精准度。
3. NDCG@K（归一化折损累计增益）：不仅考虑是否相关，还支持多级相关性打分并对靠后位置施加对数折损惩罚。
4. 零命中率（Zero-Hit Rate）与平均响应延迟（Latency P50/P95）：在线监控知识库覆盖盲区与系统吞吐性能的核心工程指标。
