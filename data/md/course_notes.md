# 数据结构与算法核心笔记

## 图的最短路径算法 (Dijkstra / Bellman-Ford / Floyd)
Dijkstra 算法采用贪心策略解决带权有向图或无向图的单源最短路径问题。它维护一个已确定最短路径的顶点集合 S，每次从集合外选择距离源点最近的顶点 u 加入 S，并对 u 的所有出边进行松弛（Relaxation）操作。在稠密图中使用数组实现的时间复杂度为 O(V^2)；在使用二叉最小堆（优先队列）优化时，时间复杂度可降低至 O((V + E) log V)，但要求所有边权必须非负，不支持包含负权边的图。

当图中存在负权边时，应采用 Bellman-Ford 算法或 SPFA（队列优化的 Bellman-Ford），其时间复杂度为 O(VE)，并可通过第 V 轮是否仍能松弛来检测负权环。若要求解所有顶点对之间的最短路径（All-Pairs Shortest Paths），可使用基于动态规划的 Floyd-Warshall 算法，状态转移方程为 dp[k][i][j] = min(dp[k-1][i][j], dp[k-1][i][k] + dp[k-1][k][j])，时间复杂度为 O(V^3)，空间复杂度优化后为 O(V^2)。

## 启发式搜索与 A* (A-Star) 算法
A* 算法是静态路网中求解最短路径最有效的直接搜索方法，其评估函数定义为 f(n) = g(n) + h(n)，其中 g(n) 表示从起点到节点 n 的实际代价，h(n) 表示从节点 n 到终点的启发式估计代价。当启发函数 h(n) 满足可采纳性（Admissible，即 h(n) 小于等于实际最短距离，例如平面路网中的欧氏距离或曼哈顿距离）时，A* 算法保证能够找到全局最优最短路径，且搜索扩展的节点数显著少于普通 Dijkstra 算法。

## 堆与优先队列及 Top-K 非完全排序
最小堆（Min-Heap）是一种完全二叉树结构，满足堆序性质：任意父节点的关键字总是小于或等于其左右子节点的关键字。最小堆底层通常使用连续数组存储，索引为 i 的节点其父节点为 (i-1)//2，左孩子为 2i+1，右孩子为 2i+2。插入元素采用上浮（Sift-Up）操作，弹出堆顶采用下沉（Sift-Down）操作，单次操作时间复杂度均为 O(log K)。

在海量数据 Top-K 推荐与筛选场景（例如从 N 个候选项中选出得分最高的 K 个）下，无需进行代价为 O(N log N) 的全局排序（如快速排序或 Timsort）。只需维护一个容量固定为 K 的最小堆：前 K 个元素直接入堆；后续元素若大于堆顶（即当前前 K 大中的最小值），则弹出堆顶并压入新元素。遍历完全部 N 个元素仅需 O(N log K) 时间复杂度与 O(K) 辅助空间，在 N 远大于 K 时性能提升数倍。

## 哈夫曼树与前缀无损压缩编码 (Huffman Coding)
哈夫曼树（最优二叉树）是带权路径长度（WPL, Weighted Path Length）最小的二叉树。哈夫曼编码通过统计文本中各字符出现的频次作为叶节点权值，利用最小堆反复合并权值最小的两棵子树，自底向上构建哈夫曼树：左分支赋予比特 0，右分支赋予比特 1。

高频字符距离树根更近，分配较短的二进制编码；低频字符分配较长的二进制编码。由于所有字符均位于叶子节点，任一字符的编码都不会成为另一字符编码的前缀（即满足前缀码 Prefix Code 性质），从而在解码比特流时无需分隔符即可实现唯一、无歧义的线性时间 O(N) 无损解压。构建哈夫曼树的时间复杂度为 O(|Σ| log |Σ|)，其中 |Σ| 为字符集大小，平均码长无限逼近信源香农熵 H(X)。

## 二叉搜索树、AVL 树与红黑树 (Red-Black Tree)
二叉搜索树（BST）满足左子树所有节点小于根节点、右子树所有节点大于根节点，平均查找时间为 O(log N)，但在有序插入下会退化为 O(N) 的单链表。AVL 树通过严格维持任意节点左右子树高度差（平衡因子）绝对值不超过 1，利用 LL、RR、LR、RL 四种旋转操作保证严格平衡，适合读多写少场景。

红黑树是一种近似平衡的二叉搜索树，通过五条性质（节点非红即黑、根为黑、叶 NIL 为黑、红节点之子必为黑、任一节点到叶子的所有路径包含相同数目黑节点）保证最长路径不超过最短路径的 2 倍。红黑树在插入和删除时最多只需 O(1) 量级的旋转操作，综合增删查改性能优异，被广泛应用于 C++ STL map/set、Java TreeMap 以及 Linux 内核进程调度 CFS 与 epoll 事件管理中。

## 哈希表与冲突解决策略
哈希表（Hash Table）通过散列函数将键映射到桶数组索引，实现理想情况下 O(1) 的平均查找、插入和删除时间复杂度。常见的哈希冲突解决方法包括链地址法（拉链法，Separate Chaining，当链表过长时可转化为红黑树）与开放寻址法（线性探测、二次探测、双重散列）。负载因子 α = 已存元素数 / 桶容量，当 α 超过阈值（通常为 0.75）时需触发 2 倍扩容与 Rehash，以维持低冲突率。

## 动态规划与贪心策略对比
动态规划（Dynamic Programming）适用于具备最优子结构、重叠子问题和无后效性的问题，通过状态定义、状态转移方程与记忆化表格（自顶向下记忆化搜索或自底向上递推）避免指数级重复计算，典型应用包括 0-1 背包、最长公共子序列（LCS）、编辑距离（Levenshtein Distance）与区间 DP。贪心算法则在每一步仅做出当前局部最优选择，不进行回溯，仅在问题满足拟阵或贪心选择性质（如活动选择、哈夫曼编码、最小生成树 Kruskal/Prim、无负权最短路 Dijkstra）时才能导出全局最优解。
